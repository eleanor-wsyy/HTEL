## 一、结构与画面规则

顺序：**首页动效与研究背景 → 背景画像（完整六维桑基）→ 人物总览 → 人物档案 → 日常对照 → 填写与缺失 → 局外人 → 片尾。** 五种填写轨迹位于总览内，在孤独水平与波动之前。

### 打字机章节页

参考用户所给图的居中双行结构。主标题使用网页对应中文标题，下一行用一句短概括。标题逐字出现，再输入概括；不以淡入整段文字代替打字机效果。主章节页除局外人11秒外均为5秒：约1.8秒标题、1秒概括、1.5秒阅读、0.7秒衔接。长标题分两行排，始终完整显示。

局外人章节页按用户新文案延长至11秒。每个新图表组前也有2—3秒短章节页，包含在该镜头的时间范围内。短章节页标题与概括输入完后保留在图表上方，不会刚打完就消失；画面数据随后绘制。章节页和图表共用纸色背景，文字退到图表标题位置，避免重复切黑屏。必须读到的数字停留至少3秒；5秒快镜头仅承担整体趋势，标签跟随进入下一镜头。
