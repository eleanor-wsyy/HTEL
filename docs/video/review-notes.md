## 一、必须修正的数据绘制问题

### 1. 圆图前两项取错数据；每日线也没有展开到扇区

`film2.py:653` 使用 `HEAT[IA,d] if m < 2 else p['daily'][d][m]`，把孤独感和低落情绪的逐日线都画成双题复合分。均值点却取对应单题，出现线和点口径不一致。

同时，每一天都使用同一个角度 `a`，75 条线重叠在一根轴上，失去了网页圆图的逐日扇区结构。

修改：八项统一读取 `person.daily[d][m]`；按日次在各扇区内分配角度，半径读取实际分数；缺失不补零。圆图名称从网页 `metrics` 获取，不再手写“被排除”“自我暴露”等与项目不一致的词。

### 2. “局外人”图的数组方向、范围都错了

`film2.py:898` 的 `ok[o2][:grow]` 截取的是前 grow 个人，grow 最大只有 75，得到最多 75×75 的数组；显示范围却写成横向 515 人。结尾不是完整 515 人的覆盖图。

修改：若横轴人、纵轴日次，应使用 `ok[o2,:grow].T`；最终数组必须是 75×515。≤15 天的 49 人边界与真实排序后的列位置一致。

### 3. 3D 五组是另一次聚类，并且只绘制少量示例

现片用 `lab5.npy`，五组人数为 **194 / 126 / 69 / 58 / 68**；每组又最多抽取 11 人，所有柱高均为 1。它不是网页的五个原稿模型，也没有呈现 0—100% 的实际高度差。片中文字“行号沿用原图”与实际代码不一致。

网页现在具备原稿矢量柱数据，可直接使用：

| 原稿分组名 | 人数 | 实际柱数 |
|---|---:|---:|
| 几乎每天填写 | 192 | 13,789 |
| 时间较短但基本连续 | 14 | 843 |
| 断断续续填写 | 242 | 12,656 |
| 5月前停止填写 | 38 | 651 |
| 填写少于7晚 | 29 | 80 |
| 合计 | 515 | 28,019 |

修改：使用 `figma-model-data.js`，不再重新聚类、不抽样、不把所有柱高设成 1；先演示一个模型的构造，再让五组进入同一尺度的比较。

补充发现：已逐行、逐连续段核验全部 515 行。所有正值编码都等于它所在连续正值段的长度，共 3,907 段、28,019 根柱全部成立。因此柱高可以解释为“原稿连续段长度的编码”，如需换算百分比为 `段长度/75×100%`。这是对原稿数据结构的验证，不是原研究变量定义。原始标注仍应保留在制作说明中；不能把它解释成每天孤独程度或单日问卷完成率，也不能据原稿行号跳接具体人物 ID。

### 4. 坐标尺误导或被隐藏

- 居住方式点图横轴只画到 4.6，最右却标成“10”，位置和标值不一致。改为完整 0—10 同尺度，或把末端明确标成 4；不能混用。
- 均值—标准差图的横轴上限是 7.2，实际最大 8.783334，漏掉 3 个高均值点。改用完整 0—10 范围。
- `Frame.ax()` 默认 `axis('off')`，后续仅设置 ticks、xlabel 不会恢复轴的显示。成片很多折线缺少明确评分和日次尺。对需要读数的图显式启用必要坐标、保留 0/5/10 与 D01/D25/D50/D75 等少量标记。

### 5. 将双题、单题、提交和相对日次分开

- 478、498 的 **孤独感单题均值均为 3.44**，SD 分别 1.89、2.51；两人的双题均值则是 **3.80、2.16**。不把双题像素直接变为单题曲线而不说明。
- 502→237 是 D01/D75 的**有效双题人数**，不是所有提交日记的人数。片中文字应据此更名。
- D01 是每个人各自入组后的第一天，不是所有人的同一个日历日。删除把 113、45 两人的跨人相对日次相关解释成“共同变化是否成立”的主结论。若保留 r，应仅作附注；主片没有必要展示。
- 28,027 是原始行数；27,785 是有效双题人日；28,019 是原稿模型柱数。这三种计数不要求相等。

## 二、叙事和节奏

原片按网页章节依次出现，几乎每段都是“标题—整图淡入—文字解释”。视频需要更明确的观察顺序。

建议新顺序：
1. 用 478、498 的同分问题开场，让观众先知道要寻找什么。
2. 退回“一人一天”，说明 515×75 的数据是怎么构成的。
3. 背景资料用短段桑基流向建立人群差异，不铺满全部网页功能。
4. 画出每个人的均值与波动，再从中选回具体人物。
5. 将八项逐日线生成圆图，最后突出孤独感并展开两人的曲线。
6. 从“有颜色的评分”切到“是否留下记录”，建立 3D 填写轨迹。
7. 3D 转俯视，以空白引入低覆盖的 49 人，最后收束全部格子。

## 三、视觉执行

- 主图占画面约 65%—75%；不要五个小 3D 模型从头并排转 20 秒。
- 标题约 64—80px，正文 32—38px，关键图例 26—30px。来源可小，但不能承载必须读到的结论。
- 每镜头采用“先画尺—出现数据—突出差异—停留阅读”，而不是所有东西一起淡入。
- 总览保持网页黄—蓝色阶；八项指标使用网页固定色；人物对照允许按人物分色，但明确标出姓名编号。
- 缺失固定灰色，不再在总览里透明、局外人里变浅红。
- 移除整幅图持续漂浮、动态噪点闪烁等与数据无关的运动；可保留极轻静态纸纹。
- 分数、人数、连续段长度切换时先换轴标签，再开始变形；不使用装饰性 360° 连续旋转。
- 结论文字一次一条，每条至少留足 3 秒；复杂图完成后留 3—4 秒静读。
