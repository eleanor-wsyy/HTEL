# FAMD 平面与日记高度

图中空间位置、日记高度与探索分组是三套独立编码。

## 数据与口径

- 基线原始样本 515 人，使用 PID 与现有网站档案连接。
- 输入九项：性别、年龄、族群、子女情况、收入原始分档、居住状况、婚恋状态、焦虑诊断史、抑郁诊断史。
- 年龄为数值；其他八项显式按分类处理。incomeN 不参加拟合，也不作为真实年收入。
- 完整案例 495 人进入 FAMD；20 人不补值，不生成坐标，仍有可访问的日记和人物档案。
- 未使用孤独感或其他日记指标拟合 FAMD、K-Means。

## 坐标与分组

- FAMD 拟合五个成分，只显示前两维。Dim1 为 13.710239%，Dim2 为 9.021702%，合计 22.731941% 惯量。
- 平面横纵轴均为实际 FAMD 得分，使用相同绘制单位，不抖动、不按日记分数重新排列。
- A/B/C 为前两维坐标上的探索性 K-Means（k=3，random_state=42，n_init=20），按中心的第一维排序重命名，不代表等级或诊断。
- 比较 k=2—6 的二维轮廓系数，当前 k=3 最高（0.431437）。五个随机起点 ARI 均为 1，只检查优化起点，不是重抽样或临床验证。
- 18 对人物在前两维同坐标。界面提供同坐标人物切换，不添加虚构抖动。

## 高度与交互

- 高度是所选日记指标在全期 D01—D75 有效日上的个人均值（0—10）。默认双题复合分，八项单题可独立切换。
- 顶面保留 15×5 个逐日格。0 分有效；无均值不画虚构的零高度，使用空心底点并标明无均值。
- 基线坐标在指标切换时不变。三维空间混合了基线坐标和独立日记单位，整体三维距离不是聚类距离。
- 原二维格子、逐日矩阵、人物卡与对比仍可使用。支持键盘、触控和减少动态效果偏好。
- 使用原生 Canvas 对真实三维顶点作正交投影；无需联网或浏览器端科学计算依赖。

## 复现

依赖锁定在 scripts/famd-requirements.txt。于隔离环境安装后运行：

    python scripts/build_famd.py --baseline <原始Baseline CSV路径>
    python scripts/build_standalone.py
    npm test

输出 data/famd.json，并给 data/study.json 增加独立的 famd 字段。原 people、metrics、meta、order 和 referenceMeans 保持不变。分析版本、原始文件哈希、缺失原因、模型参数和验证结果保存在分析 JSON。
