# 《看见孤独》BB-Video版分镜：从515人到两个人

## 用户确认的方向

本版先讲全体515人，从大到小，不用478、498两个人开场。问题依次是：有多少人 → 他们是谁 → 日常如何进入总览 → 记录留下什么形状 → 哪些日常记录不足 → 一个人的感受怎样展开 → 同分的人是否有相同日常。

延续横版1920×1080、30fps、180秒、静音；不新增音乐、旁白或竖版。风格选择BB-Video Swiss动态排版，使用项目纸色和深蓝。图表是固定真实数据的程序化绘制，不是将旧视频换名或套滤镜。

## 转场的逻辑

- 背景桑基是同一批人的分类交叉，不是状态随时间迁移。
- 总览重排移动真实人物格，格内数据不能交叉淡化成另一个人的数据。
- 日记评分与3D填写形状是不同观测对象。进入3D要换轴、换说明，不将3D高度误作孤独感。
- 3D模型原稿行号没有人物映射，退出3D后明确切换数据源，不能让“少于7晚29人”直接变成“≤15有效双题日49人”。
- 478在总览和个人日记格里用双题分3.80；进入圆图后明确切换八项单题，其孤独感单题均值3.44。对照只比较同一单题。
- 结尾重新出现整体规模是收束，不再开启新的大样本分析。
